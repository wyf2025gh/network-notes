# 计算机网络笔记

计算机网络技术专业的课程笔记与 eNSP 实验记录。

手机、平板、任何一台电脑打开这个链接就能看，不用带 U 盘。

电脑上的位置：`E:\网络命令`　←　所有命令都在这个文件夹里敲

---

## 我怎么往里加笔记

### 方法一：命令行（三步，最稳）

在这个文件夹里打开终端，敲：

```bash
git add .
git commit -m "记了 OSPF 邻居建立"
git push
```

### 方法二：VS Code 点鼠标（同一个意思）

| 界面上的东西 | 等于 |
| --- | --- |
| 文件右边的 `+` | `git add` |
| 消息框写说明 + 点 `✓` | `git commit` |
| 左下角「同步更改」 | `git push` |

> 忘了命令就 `git status`，它会告诉你现在是什么情况。
