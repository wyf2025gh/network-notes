【一、拓扑速览】

  PC1 ---- AR1 ---- AR2 ---- AR3 ---- AR4 ---- PC2

  +-------------------+-------------------+-------------------+
  |   区域 49.0001    |    Level-2 骨干   |   区域 49.0002    |
  |      （L1）       |                   |      （L1）       |
  +-------------------+-------------------+-------------------+

  设备角色：

  AR1  Level-1        末梢路由器，路由表里只有一条默认路由
  AR2  Level-1-2      ABR，一只脚在 49.0001，一只脚在骨干
  AR3  Level-1-2      ABR，一只脚在骨干，一只脚在 49.0002
  AR4  Level-1        末梢路由器，路由表里只有一条默认路由

  连接表（5 根线，全程 Copper，不要用 Serial）：

  +------+-------------------+-------------------+--------------+
  | 序号 | A 端              | B 端              | 承载网段     |
  +------+-------------------+-------------------+--------------+
  |  1   | PC1 Ethernet0/0/1 | AR1 GE0/0/0       | 192.168.1.0  |
  |  2   | AR1 GE0/0/1       | AR2 GE0/0/0       | 10.1.12.0    |
  |  3   | AR2 GE0/0/1       | AR3 GE0/0/0       | 10.1.23.0    |
  |  4   | AR3 GE0/0/1       | AR4 GE0/0/0       | 10.1.34.0    |
  |  5   | AR4 GE0/0/1       | PC2 Ethernet0/0/1 | 192.168.2.0  |
  +------+-------------------+-------------------+--------------+

  全部是 /24，不划 /30，本题不考地址规划，只考 IS-IS 分级。

================================================================

  +------+-----------+-------------------+--------------+
  | 设备 | 接口      | 地址              | 备注         |
  +------+-----------+-------------------+--------------+
  | AR1  | GE0/0/0   | 192.168.1.254/24  | PC1 网关     |
  | AR1  | GE0/0/1   | 10.1.12.1/24      |              |
  | AR2  | GE0/0/0   | 10.1.12.2/24      |              |
  | AR2  | GE0/0/1   | 10.1.23.2/24      |              |
  | AR3  | GE0/0/0   | 10.1.23.3/24      |              |
  | AR3  | GE0/0/1   | 10.1.34.3/24      |              |
  | AR4  | GE0/0/0   | 10.1.34.4/24      |              |
  | AR4  | GE0/0/1   | 192.168.2.254/24  | PC2 网关     |
  +------+-----------+-------------------+--------------+

  NET 地址（本题最容易错的地方）：

  +------+--------------------------------+----------+----------+
  | 设备 | NET                            | Area ID  | 级别     |
  +------+--------------------------------+----------+----------+
  | AR1  | 49.0001.0000.0000.0001.00      | 0001     | L1       |
  | AR2  | 49.0001.0000.0000.0002.00      | 0001     | L1-2     |
  | AR3  | 49.0002.0000.0000.0003.00      | 0002     | L1-2     |
  | AR4  | 49.0002.0000.0000.0004.00      | 0002     | L1       |
  +------+--------------------------------+----------+----------+

  NET 四段，一段都不能少：

    49      AFI，固定 49（私有地址域，实验室标准用法）
    0001    Area ID，本题两个区域分别是 0001 / 0002
    0000.0000.0001   System ID，必须 6 字节，写出来是 12 位十六进制
    00      NSEL，恒为 00

  IS-IS 没有 OSPF 那样的 router-id 命令，System ID 就是它的身份。
  习惯上把 1.1.1.1 这种地址补成 0010.0100.0001 来当 System ID，
  本题直接用 0000.0000.000N，一眼能对上设备编号，更方便排错。

  区域划分（注意 10.1.23.0/24 同时出现在两级里，见第七节第 6 条）：

  +-------------------+---------------------------------------+
  | 区域              | 包含的网段                            |
  +-------------------+---------------------------------------+
  | L1 / 49.0001      | 192.168.1.0/24、10.1.12.0/24、        |
  |                   | 10.1.23.0/24                          |
  | L2 / 骨干         | 10.1.23.0/24                          |
  | L1 / 49.0002      | 10.1.23.0/24、10.1.34.0/24、          |
  |                   | 192.168.2.0/24                        |
  +-------------------+---------------------------------------+

【五、验证命令】
================================================================

  ① 邻居与级别（先看这个）
  --------------------------------------------------------------
  在 AR1：display isis peer
    期望 1 条，对端 0000.0000.0002，接口 GE0/0/1，Type = L1
  在 AR4：display isis peer
    期望 1 条，对端 0000.0000.0003，接口 GE0/0/0，Type = L1
  在 AR2：display isis peer
    期望 2 条：0000.0000.0001 走 GE0/0/0 是 L1，
              0000.0000.0003 走 GE0/0/1 是 L2
  在 AR3：display isis peer
    期望 2 条：0000.0000.0002 走 GE0/0/0 是 L2，
              0000.0000.0004 走 GE0/0/1 是 L1

  合计 6 条邻居。AR1 上出现 Type = L2，说明 AR1 级别配错了。

  ② ATT 位（本题核心之一）
  --------------------------------------------------------------
  在 AR2：display isis lsdb level-1

    最后一列的表头是 ATT/P/OL，期望看到：

    0000.0000.0002.00-00*  ...  ...  ...  ...  1/0/0

    带 * 的是自己产生的 LSP，ATT = 1 表示"我连得上骨干"。
    AR1 的 LSP（0000.0000.0001.00-00）那一列必须是 0/0/0。

  ③ 两边 L1 路由表（本题核心之二）
  --------------------------------------------------------------
  在 AR1：display ip routing-table

    0.0.0.0/0      ISIS-L1   15   10   -> 10.1.12.2
    10.1.23.0/24   ISIS-L1   15   20   -> 10.1.12.2
    （加直连和 127 段，共 12 条）

    必须满足两点：
      - 有 0.0.0.0/0，下一跳指向 10.1.12.2（AR2）
      - 没有 192.168.2.0/24，也没有 10.1.34.0/24

  在 AR4：display ip routing-table

    0.0.0.0/0      ISIS-L1   15   10   -> 10.1.34.3
    10.1.23.0/24   ISIS-L1   15   20   -> 10.1.34.3
    （共 12 条）

  两边都不许出现对端的业务网段明细，出现就是级别配错。

  ④ 中间设备怎么看对端网段
  --------------------------------------------------------------
  在 AR2：display ip routing-table 192.168.2.0

    期望 192.168.2.0/24  ISIS-L2  15  30  -> 10.1.23.3

    L1 的网段可以由 ABR 上漏到 L2，所以 AR2 看得到，
    但 AR2 不会把它再塞回 L1，AR1 永远看不到。

  ⑤ 端到端
  --------------------------------------------------------------
  PC1：ping 192.168.2.10
    期望 4/5 或 5/5，ttl = 124
    128 - 4 = 124，经过 AR1、AR2、AR3、AR4 四次转发
    首包超时属于 ARP + IS-IS 首次收敛，正常现象

  AR1：ping -a 192.168.1.254 -c 4 192.168.2.10
    期望 ttl = 125

  同一个目的，PC 上 124、AR1 上 125，因为源设备自己不算一跳。

【六、本题实测踩坑记录】
================================================================

  坑 1：AR4 配成 level-2，靠 L2 明细"假通过"
  --------------------------------------------------------------
  现象：PC1 ping 192.168.2.10 完全通、ttl 也对，看起来做完了。
  真相：AR4 的 is-level 写成了 level-2，它的路由表里全是
        ISIS-L2 明细（10.1.12.0/24、10.1.23.0/24、192.168.1.0/24），
        根本没有走 L1 + ATT 那套机制。
        区域 49.0002 里一台 L1 路由器都没有，AR3 的 L1 半边空转，
        "双区域"实际退化成了"骨干加一个挂件"。
  判据：看 AR4 路由表的 Proto 列。应该是 ISIS-L1，出现 ISIS-L2
        就是级别错了；再看条目数，L1 只有 12 条左右，L2 会带全量。
  修法：isis 1 -> is-level level-1，改完邻居自动重建。
  教训：ping 通不等于考点做到。IS-IS 题必须看 Proto 列。

  坑 2：NET 的 System ID 少写一段或写成 4 位
  --------------------------------------------------------------
  System ID 固定 6 字节 = 12 位十六进制，写成 0000.0001 会被
  拒绝（提示格式错误），写成 0000.0000.0001.00 是正确形态。
  四段结构少任何一段都不行，最后的 .00 也不能省。

  坑 3：接口忘敲 isis enable 1
  --------------------------------------------------------------
  IS-IS 没有 network 命令，接口不 enable 就不参与，该网段既不进
  L1 也不进 L2。现象是邻居只有一边通、路由表缺网段。
  排查：display isis interface，看接口在不在列表里。

  坑 4：先 isis enable 再建进程
  --------------------------------------------------------------
  接口下 isis enable 1 时进程不存在，命令能敲进去但不生效，
  建完进程要回接口再敲一次。正确顺序：进程 -> NET -> 接口。

  坑 5：两个 L1 区域 ID 不一致，物理直连也建不了邻居
  --------------------------------------------------------------
  L1 邻居的前提是 Area ID 相同（0001 对 0001）。
  49.0001 和 49.0002 之间只能建 L2 邻居，这是协议规定，
  不是配置问题。所以 AR2 必须是 L1-2，它靠 L2 那半边跨区域。

  坑 6：以为 L1 能收到明细，手工加静态路由去补
  --------------------------------------------------------------
  L2 的明细从设计上就不下发给 L1，AR1 只该有一条默认路由。
  看到"缺路由"就去加静态，反而破坏了 ATT 机制，考试直接扣分。
  默认路由的下一跳由 ATT 位自动算出来，不用手配。

【七、设计点说明】
================================================================

  1. 为什么 L1 路由器只拿到一条默认路由
     L1 的 LSDB 里只装本区域的 LSP，L2 的明细不会下发（IS-IS 没
     有 OSPF 那种 Type-3 翻译机制）。ABR 唯一做的事，是在自己的
     L1 LSP 里把 ATT 位置 1。L1 路由器看到 ATT=1，就自己造一条
     0.0.0.0/0 指向那台 ABR。
     好处：末梢设备路由表只有十几条，骨干几万条也不影响它；
     骨干抖动，边缘根本感知不到。这是分级的全部意义。

  2. ATT 到底是谁置的、开销怎么算
     ATT 只由 L1-2 路由器在"自己的 L1 LSP"里置 1，纯 L1 和纯 L2
     都不置。AR1 的 LSP 里 ATT 必须是 0，AR2 的必须是 1。
     默认路由的开销 = 到那台 ABR 的开销，不含远端。所以 AR1 上
     是 10（一条链路），不是整条路径的开销。

  3. 为什么 ABR 必须是 level-1-2
     一只脚在区域内（L1），一只脚在骨干（L2）。缺 L2 那只脚，
     就跟骨干断了，ATT 无处可置；缺 L1 那只脚，区域内没人认得它。
     AR2 少了任何一半，49.0001 立刻成孤岛。

  4. 为什么 IS-IS 没有 network 命令
     OSPF 是"把网段宣告进进程"（network 网段 反掩码），改地址忘
     了改 network 就断。IS-IS 是"把接口挂到进程上"（isis enable 1），
     网段由接口 IP 自动生成。
     根子在出身：IS-IS 来自 OSI 的 CLNS，管的是链路，路由信息由
     接口的链路状态自然产生；OSPF 是纯 IP 协议，必须显式声明。
     衍生好处：加地址、加子接口都不用回头改宣告。

  5. L1 到 L2 上漏允许，L2 到 L1 下发禁止
     AR3 把 AR4 的 192.168.2.0/24 放进自己的 L2 LSP，所以 AR2 能
     看到（ISIS-L2，开销 30）。但这个方向到此为止，AR2 不会把它
     再塞进 L1。一句话：明细可以往上走，不能往下走。

  6. 为什么 10.1.23.0/24 在 AR4 上是"区域内"路由
     AR2、AR3 都是 L1-2，它们的接口网段会同时出现在 L1 和 L2 两种
     LSP 里。AR3 的 L1 LSP 带着 10.1.23.0/24，所以 AR4 认为这段
     跟自己同区域，算作 ISIS-L1、开销 20（AR3 那段 10 + 本段 10）。
     这不是配错，是 L1-2 路由器的正常行为。

【八、三个思考题的答案要点】
================================================================

  1. 为什么 L1 路由器只拿到默认路由，而不是所有区域外网段？
     协议规定 L2 明细不下发给 L1，ABR 只用 ATT 位告诉 L1"我能出
     区域"，L1 据此自己生成 0.0.0.0/0。目的是让边缘保持轻量：
     路由表小、收敛快、骨干变化不外溢。类比：小区住户只需要知道
     "出小区走大门"，不用背全市地图。

  2. 如果 AR2 的 is-level 改成 level-1，AR1 还能通 192.168.2.10 吗？
     不能。L1 邻居要求区域 ID 相同，AR2 是 0001、AR3 是 0002，
     改完 L1 也建不成；而 AR2 又不再有 L2 能力，跟 AR3 一条邻居
     都不剩。结果：AR2 的 L2 LSDB 空，ATT 归 0，AR1 连默认路由
     都收不到，49.0001 彻底孤立。

  3. IS-IS 宣告网段用 network 命令吗？为什么和 OSPF 不一样？
     不用。接口下 isis enable 1 即宣告，网段由接口地址自动生成。
     因为 IS-IS 出身 CLNS，路由信息来自接口链路状态；OSPF 是纯 IP
     协议，必须用 network 显式声明谁参与。只有引入外部路由时才用
     import-route，那是 ASBR 的活。
